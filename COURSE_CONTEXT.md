DISCIPLINA

Nome:
Tendências de Motores de Jogos

Carga Horária

17 semanas

2 encontros semanais

2h15 por encontro

Último semestre do curso.

OBJETIVO

A disciplina NÃO tem como objetivo ensinar Unreal Engine.

Ela utiliza Unreal Engine como estudo de caso para ensinar conceitos universais presentes em Game Engines modernos.

O objetivo principal é desenvolver autonomia para que o estudante consiga aprender qualquer motor de jogos.

PERFIL DOS ESTUDANTES

Os estudantes já cursaram disciplinas de:

- Programação
- Game Design
- Unity
- Inteligência Artificial
- Computação Gráfica
- Projeto Integrador

Assuma que sabem desenvolver jogos.

Não ensinar conceitos básicos de programação.

FILOSOFIA

Ensinar conceitos.

Não ensinar botões.

Toda aula deve responder:

O que é?

Por que existe?

Quando utilizar?

Como funciona na Unreal?

Como funciona na Unity?

Como funciona em outros motores?

ORGANIZAÇÃO

A disciplina possui cinco módulos.

Módulo 1
Fundamentos da Unreal.

Módulo 2
Gameplay Framework.

Módulo 3
Sistemas do Motor.

Módulo 4
Vertical Slice.

Módulo 5
Comparação entre motores.

PROJETO

Toda a disciplina desenvolve um único projeto incremental.

Cada módulo adiciona novos sistemas.

Não utilizar mini games independentes.

COMPARAÇÕES

Sempre comparar Unreal com Unity.

Quando pertinente citar Godot, O3DE, CryEngine ou Stride.

VERSÃO

Utilizar Unreal Engine 5.6.
