## Visão geral da disciplina

- **Carga horária:** 17 semanas letivas, 6 h/a semanais (102 h/a — 76h) — último semestre do curso.
- **Estudo de caso principal:** Godot 4.7, com o addon Orchestrator (visual scripting), usado para ensinar conceitos universais de game engines e facilitar a transição entre motores (com comparações constantes a Unity e, quando pertinente, Unreal Engine, O3DE e Stride).
- **Projeto:** um único Vertical Slice incremental, construído ao longo de todo o semestre — cada módulo adiciona novos sistemas sobre o mesmo projeto.
- **Progressão pedagógica:**
  - Módulo 1 — Aprender a ferramenta (Scaffolded Learning)
  - Módulo 2 — Construir sistemas (Studio Based Learning)
  - Módulo 3 — Resolver problemas (Challenge Based Learning)
  - Módulo 4 — Produzir como um pequeno estúdio
  - Módulo 5 — Comparar arquiteturas e aprender novos motores (Engenharia Reversa)

## Se você está assumindo esta disciplina pela primeira vez

O Manual do Professor foi escrito exatamente para esta situação: ele parte do princípio de que qualquer professor, lendo-o junto com os demais documentos, deve conseguir conduzir o semestre mantendo a mesma filosofia pedagógica e os mesmos critérios de avaliação — independentemente de quem esteja à frente da sala. Preste atenção especial à distinção entre "aprender Godot" e "aprender conceitos de game engines": o Godot é o veículo, nunca o destino.
